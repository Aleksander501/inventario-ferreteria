# inventario-ferreteria
El Sistema de Inventario para la Ferretería Santa Lucía es una aplicación web desarrollada para optimizar la gestión de productos, proveedores, usuarios y reportes, brindando un control centralizado y seguro de las operaciones internas de la ferretería


🎯 Objetivos

Automatizar el control de inventario, reduciendo errores manuales.

Facilitar el registro y consulta de productos, categorías y proveedores.

Mejorar la seguridad y trazabilidad mediante gestión de usuarios con roles.

Generar reportes dinámicos en PDF para apoyar la toma de decisiones.

🛠️ Funcionalidades principales

Autenticación de usuarios

Módulo de registro e inicio de sesión seguro.

Roles: Administrador y Auxiliar.

Gestión de productos

Alta, baja, modificación y consulta de productos.

Control de stock y clasificación por categorías.

Gestión de categorías

Creación y mantenimiento de categorías para organización del inventario.

Gestión de proveedores

Registro de proveedores y administración de datos de contacto.

Gestión de usuarios

Administración de cuentas de usuario.

Definición de permisos por rol.

Generación de reportes

Exportación de reportes en PDF para inventario, movimientos y proveedores.

💻 Tecnologías utilizadas

Backend: PHP, MySQL.

Frontend: HTML, CSS, JavaScript, AJAX.

Servidor local: Apache (LAMP/XAMP según el entorno de trabajo).

Control de versiones: Git y GitHub.

Gestión de proyecto: Jira Software.

🚀 Beneficios esperados

Mayor eficiencia en la gestión de inventario.

Reducción de pérdidas y sobrecostos por descontrol en existencias.

Centralización de la información de productos y proveedores.

Mejor seguridad en el acceso a la plataforma.

Informes claros para decisiones de compra y ventas.
